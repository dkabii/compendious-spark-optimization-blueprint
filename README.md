# Compendious Spark Optimization Blueprint

The code is used to setup a spark cluster and a pyspark dev environment.

## Spark Cluster

To get started, you can create the cluster by navigating to the spark-cluster folder.
From there, run the code using the command:

```
docker compose up --build
```

## Spark Development Environment

To get started with spark development by navigating to the spark-dev folder.
From there, run the code using the command:

```
docker compose up --build
```

If using local mode, the spark cluster does not have to be up and running.
